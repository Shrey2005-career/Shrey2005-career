## 🚀 Featured Project

### Personalized RAG Assistant

A Python-based AI assistant that uses **Retrieval-Augmented Generation**, **user memory**, and **behaviour analytics** to provide more relevant and personalized answers.

* Built a RAG pipeline using Python, Gemini, ChromaDB, and Sentence Transformers
* Implemented semantic search, query rewriting, and re-ranking
* Added JSON-based user memory for storing conversations and user activity
* Used behaviour analytics to personalize responses based on user patterns

🔗 **Project Repository:** [https://github.com/Shrey2005-career/personalized-rag-assistant]
